**Format:** Screen recording (app demo) + voice narration
**Tone:** Fun, confident, conversational
**Narration:** You (no face on camera, just your voice + app screen)

## Production Tips

### Recording Setup
| Element | Recommendation |
|---|---|
| **Voice** | Record your narration with a clean mic (or even phone headphones) in a quiet room |
| **Screen** | Record the CHEA app itself as you demo each feature |
| **No face** | Camera only shows the app screen and on-screen text |
| **Background** | Dark cyberpunk style matches CHEA's theme |
| **Transitions** | Fast cuts between features (2-3 seconds each) |
| **Music** | Upbeat electronic/cyberpunk track (no vocals) — free on Pixabay or YouTube Audio Library |
| **Text overlay** | Key phrases appear on screen as you say them |

### Screen Recording Tips
| Element | Tip |
|---|---|
| **Demo each feature** | Open the app, record yourself clicking through each tool |
| **Use keyboard shortcuts** | Record in one take per feature |
| **Add UI callouts** | Arrows/boxes highlighting what you're talking about |
| **Keep it fast** | 2-3 seconds per feature, 5-8 seconds per game |

### What to Record on Screen
| Time | What to Show |
|---|---|
| 0:00–0:20 | Intro card (name + project title + CHEA logo) |
| 0:20–0:50 | Montage of breach news, phishing examples (can use screenshots from news sites) |
| 0:50–1:40 | App walkthrough — each feature in action |
| 1:40–2:10 | Games — each game showing 5-10 seconds of gameplay |
| 2:10–2:25 | Nova chatbot answering a question |
| 2:25–2:40 | Dashboard — XP bar, level, streak, daily quests |
| 2:40–2:55 | Closing logo + thank you card |

## Recording Checklist

- [ ] Script practiced 3+ times
- [ ] Voice recording done (mic quality check)
- [ ] Screen recorded — all features demo'd
- [ ] Background music added
- [ ] Transitions are fast and smooth
- [ ] Total duration under 3 minutes
- [ ] Audio is clear (no echo, no background noise)
- [ ] Text overlays added for key phrases
- [ ] Arabic version recorded (required per guide)

---

## Recording Order

1. **Write your name/university** on the intro card
2. **Record screen** — open the app, demo each feature in order
3. **Record voice narration** separately (you can do multiple takes)
4. **Sync voice to screen** in video editor (Capcut, DaVinci Resolve, etc.)
5. **Add background music**
6. **Add text overlays** for key phrases
7. **Export — 1080p minimum**

---

## Arabic Version (Required)

After the English version, record the Arabic translation:

- Keep the same scene order and timing
- Translate naturally (not word-for-word) — aim for conversational Arabic
- Add Arabic captions/subtitles
- Total duration still under 3 minutes
- Update the intro card with Arabic text and your name in Arabic
