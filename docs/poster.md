## Abstract

This project addresses the critical vulnerability of students aged 9–15 amidst a reported 300% surge in cyberattacks targeting the education sector. Students lack routine "Cyber Hygiene" necessary to mitigate risks like weak passwords and phishing, often finding professional tools too complex. The Cyber Hygiene Educator & Assistant (CHEA) was developed as a unified Windows application combining active protection with gamified education. The system integrates five core modules: secure Password Vault, real-time Malware Scanner, Encryption tools, URL Safety Checker, and an AI-driven learning assistant. Implementation results confirm that the application successfully simplifies enterprise-grade security concepts for novice users, bridging the gap between theoretical awareness and practical utility.

## Objectives

1. Develop a unified cybersecurity platform combining protection tools with educational content
2. Target students aged 9–15 with age-appropriate interfaces and visual feedback
3. Integrate five core security modules: Password Vault, Malware Scanner, Encryption Tools, URL Checker, and AI Assistant
4. Implement gamification features (XP, rankings, badges, quizzes) to enhance engagement
5. Provide free access to eliminate economic barriers to digital safety
6. Bridge the gap between theoretical awareness and practical cybersecurity habits

## Methodology

### Research & Requirements
- Systematic literature review of 26 peer-reviewed sources
- Analysis of 6 major existing platforms (KnowBe4, Hack The Box, Bitwarden, VirusTotal, Google Interland)
- Online survey of 69 students (ages 8-18)

### System Design
- Process Model: Agile/Scrum framework
- Architecture: Desktop application using Tauri (React + TypeScript + Rust)
- Database: SQLite with AES-256-GCM encryption for local storage
- AI Integration: OpenRouter API with 6 AI-powered features

### Implementation Modules
1. **Password Generator & Strength Analyzer** - Creates and evaluates secure passwords
2. **URL Safety Checker** - Integrated with VirusTotal API for threat detection
3. **Smart File Scanner** - Hash verification for malware detection
4. **Photo Metadata Wiper** - Removes EXIF data for privacy
5. **Encryption/Decryption Lab** - Hands-on cryptographic exploration

### AI-Powered Features
- AI Security Buddy (personalized daily challenges)
- AI Scenario Simulator (interactive decision-making)
- AI Attack Narrative Generator (story-based learning)
- AI Scan Analysis (plain-language explanations)
- AI Phishing Email Generator (adaptive training)
- AI Security Posture Insights (personalized recommendations)
