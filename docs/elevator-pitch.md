# CHEA - 90-Second Elevator Pitch

---

**"What if we could stop cyberattacks — by teaching kids to protect themselves?"**

---

Cyberattacks on schools have surged **300%** since 2020. **81% of breaches** start with weak passwords. Yet every security tool is built for adults.

**Meet CHEA** — the Cyber Hygiene Educator & Assistant.

A free Windows app that protects students aged 9–15 while teaching them to stay safe online.

---

**Five core tools:**
→ Password Vault with military-grade encryption
→ Link & File Scanner using VirusTotal's 70+ engines
→ Encryption Lab for hands-on cryptography learning
→ Phishing Dojo for interactive training
→ Quiz Arena with XP rewards and rankings

**Six AI-powered features:**
→ Security Buddy delivers daily challenges
→ Scenario Simulator tests decision-making
→ Scan Analysis explains threats in plain language
→ Attack Narratives show how hackers crack passwords
→ Security Posture gives personalized report cards

---

**Why it matters:**

Current solutions force students to choose between fragmented tools, expensive subscriptions, or boring training. CHEA puts protection and education in ONE free app — with a game that makes cyber hygiene addictive.

---

**The impact:** Students earn XP, level up from Rookie to Cyber Supreme, and build daily streaks — turning security into a habit.

**One app. Free. For every student.**

*Because digital safety shouldn't be a privilege.*
